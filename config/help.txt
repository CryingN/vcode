Usage:
 vcode			Start interactive mode
 vcode up		Auto-update vcode
 vcode help		Print this help message
 vcode history		List all history session
 vcode print <id>	Print history session <id>

Interactive commands:

 /help
	Show this help message and exit.

 /model
	List all available model's <id>.

 /model <id>
	Switch the current model to <id>.
	Use /model without arguments to see valid names.

 /plan
	Change the model to plan mode.

 /build
	Change the model to build mode.

 /history
        List all history session's <id>.

 /history <id>
        Load the history session <id> to continue the conversation.
        The <id> is named by the session's start time (YYYYMMDD_HHmm).
        Use /history without arguments to see valid ids.

 /print <id>
	Print the history session <id>.

 /new
        Start a new session.

 /up
	Auto-update vcode.

 /exit
	Exit the interactive program.
